# 숏폼(Shorts) 후보 자동 채점 도구

기존 유튜브 영상(= `content/cards/*.md`) 2,000여 개를 **숏폼으로 재활용**할 때
"어떤 영상부터 클립을 뽑을지" 우선순위를 자동으로 매겨 주는 도구입니다.

> 전략적 위치: 이것은 "콘텐츠를 새로 만드는 자동화"가 아니라, **이미 검증된
> 콘텐츠를 재활용하는 파이프라인의 첫 부품**입니다. 숏폼은 차가운 신규 시청자를
> 데려오는 발견(top-of-funnel) 채널이고, 그 유입을 롱폼·멤버십으로 전환하는 것이
> 목표입니다.

## 사용법

```bash
# 공개영상(public)만 채점 → CSV 생성 (기본)
python3 tools/shorts-ranking/rank_shorts.py

# 상위 25개를 콘솔에 바로 보기
python3 tools/shorts-ranking/rank_shorts.py --top 25

# 멤버십 영상까지 전체 채점 (멤버십 티저 클립 후보용)
python3 tools/shorts-ranking/rank_shorts.py --all --out tools/shorts-ranking/shorts_ranking_all.csv
```

결과는 `shorts_ranking.csv` 로 저장됩니다 (엑셀에서 바로 열림, UTF-8 BOM).

## 채점 방식 (3개 축, 각 5점 · 최대 15점)

| 축 | 의미 | 무엇을 보는가 |
|---|---|---|
| **reach** (대중 검색성) | 일반인이 검색·걱정하는 주제인가 | 제목·태그의 주제 키워드(당뇨·고혈압·간 등 = 높음, 생리학 심화 = 낮음) |
| **hook** (훅 강도) | 통념을 깨거나 궁금증 격차를 만드는가 | 질문형 / 통념파괴("정말·항상·오해") / 위험·공포 패턴 |
| **fit** (숏폼 적합성) | 30~60초 하나의 완결 인사이트인가 | 난이도(L1↑/L3↓) + 시각화 용이 소재(위치·단계·구분 등) |

동점 구간은 **신호 풍부도(richness)**로 2차 정렬합니다 — 훅·시각화 신호가 많고,
특히 통념파괴 훅(공유·댓글 유발이 큼)을 가진 영상이 위로 올라옵니다.

## 중요한 한계 (반드시 읽을 것)

이 점수는 **제목·주제 메타데이터 기반의 "추정" 우선순위**입니다. 영상 내용을
직접 분석한 것이 아닙니다. 따라서:

- **최종 판단은 유튜브 스튜디오 애널리틱스와 교차 검증**하세요. 이미 노출·
  시청지속률·검색유입이 좋은 영상이 진짜 1순위 클립 후보입니다.
- 채점 규칙(키워드·패턴)은 `rank_shorts.py` 상단 상수에 데이터로 분리돼 있어,
  주제가 바뀌면 손쉽게 조정할 수 있습니다.

## 활용 흐름

1. CSV 상위 후보에서 영상 선택 → 유튜브 애널리틱스로 교차 검증
2. 해당 롱폼에서 가장 강한 30~60초 구간을 클립
3. 첫 2초에 훅(통념파괴/공포/궁금증) 배치, 자막 필수
4. 끝에 "전체 강의는 멤버십/사이트에서" CTA 통일 → 발견을 전환으로 연결
